# Lean SEO V1 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build the first shippable Lean SEO plugin with custom-table storage, native Gutenberg sidebar editing, and frontend SEO output.

**Architecture:** The plugin uses registered post meta only as a WordPress editor compatibility layer. All Lean SEO reads and writes are intercepted and redirected into `wp_leanseo_data` through a centralized `DataStore`, which is also used by frontend rendering. JavaScript stays thin and native by relying on `useEntityProp()` plus `@wordpress/components`.

**Tech Stack:** PHP 8.1+, WordPress 6.4+, PHPUnit, Node.js, `@wordpress/scripts`, Gutenberg packages

```php
<?php

namespace LeanSEO;

defined( 'ABSPATH' ) || exit;

final class Data_Store {
	public function normalize_row( array $row ): array {
		return [
			'post_id'         => (int) ( $row['post_id'] ?? 0 ),
			'meta_title'      => (string) ( $row['meta_title'] ?? '' ),
			'meta_desc'       => (string) ( $row['meta_desc'] ?? '' ),
			'robots_noindex'  => ! empty( $row['robots_noindex'] ) ? 1 : 0,
			'robots_nofollow' => ! empty( $row['robots_nofollow'] ) ? 1 : 0,
			'schema_type'     => (string) ( $row['schema_type'] ?? 'none' ),
			'updated_at'      => $row['updated_at'] ?? null,
		];
	}
}
```

```php
	}
}
```

```php
namespace LeanSEO;

defined( 'ABSPATH' ) || exit;

final class Frontend {
	public function __construct( private Data_Store $store ) {}

	public function build_description_tag( array $seo ): string {
		if ( empty( $seo['meta_desc'] ) ) {

	}
}
```
